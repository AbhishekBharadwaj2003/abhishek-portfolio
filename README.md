# Abhishek Bharadwaj — Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser, or run a local static server from this folder:

   ```bash
   python -m http.server 8000
   ```

3. Visit `http://localhost:8000`.

## Deploy

The site is static and can be deployed directly to GitHub Pages, Netlify, or Vercel. Upload the contents of this folder; no build command is required.
